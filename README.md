# TPI_FoodStore - Sistema de Gestión de Pedidos

## Descripción
Proyecto integrador desarrollado en Java para la materia **Programación 2 (UTN - TUP)**. El sistema es una aplicación de consola para la gestión de productos, categorías, usuarios y pedidos de un negocio gastronómico ("Food Store"), aplicando principios de Programación Orientada a Objetos (POO).

## Características Técnicas
- **Lenguaje:** Java 21.
- **Arquitectura:** Diseño por capas (Entidades, Servicios, Excepciones).
- **Persistencia:** Almacenamiento en memoria mediante el uso de Colecciones (`ArrayList`).
- **Validaciones:** Manejo de excepciones personalizadas para asegurar la integridad de los datos.
- **POO:** Implementación de herencia, interfaces (`Calculable`) y polimorfismo.

## Estructura del Proyecto
- `integrado.prog2.entidades/`: Modelado de clases según diagrama UML.
- `integrado.prog2.service/`: Lógica de negocio y reglas de validación.
- `integrado.prog2.exception/`: Manejo de errores específicos del dominio.

## Cómo ejecutar el proyecto
1. Clonar el repositorio: `git clone https://github.com/NaylaRa/TPI_FoodStore.git`
2. Abrir el proyecto en NetBeans o IntelliJ IDEA.
3. Ejecutar la clase `Main.java` ubicada en el paquete `integrado.prog2`.
